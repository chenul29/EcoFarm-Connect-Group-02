  • Click on crop row
  • Click button
  • Edit any field
  • Update growth stage & health

  • Click on crop row
  • Click button
  • Confirm deletion

  • Click button

  • Click to reload latest data

┌───────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                               │
└───────────────────────────────────────────────────────────────┘

Problem: Table empty
Solution: Run SQL script first

Problem: Can't add crop
Solution: Fill all required fields (name, both dates)

Problem: Date error
Solution: Use YYYY-MM-DD format

Problem: Changes not saved
Solution: Click "Save" or "Update" button
